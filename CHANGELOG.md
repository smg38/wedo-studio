# Changelog

## [2.5.0] - 2026-09-04
### Добавлено
- Поле "Название проекта" с сохранением в YAML.
- Подсветка выполняемых блоков в реальном времени.
- Нумерация строк в файлах проектов для отладки.
- Поддержка читаемых имен переменных в YAML (вместо ID).
- Два режима сборки: Local (Python) и Server (Nginx).

### Исправлено
- Ошибка `workspace.getVariable is not a function` при загрузке проектов.
- Потеря блоков внутри циклов при сохранении.
- Дублирование теневых блоков (чисел) при перетаскивании.

## [2.0.0] - 2026-09-03
- Первый публичный релиз.
- Поддержка моторов, LED, циклов, условий, переменных.
- Формат сохранения YAML.
