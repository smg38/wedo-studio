ИНСТРУКЦИЯ ПО РАЗВЕРТЫВАНИЮ (CLOUD/STATIC)
==========================================
Этот пакет содержит только статические файлы.
Для запуска просто загрузите содержимое папки 'web' на любой веб-сервер (GitHub Pages, Netlify, обычный хостинг).

ВАЖНО:
1. Сервер должен поддерживать HTTPS (обязательно для Web Bluetooth).
2. Не меняйте структуру папок (js/, lib/ должны лежать рядом с index.html).
