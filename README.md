# WeDo Studio v2.5

Среда визуального программирования для LEGO WeDo 2.0 Smart Hub.
Работает полностью офлайн в браузере Chrome/Edge.

## 🚀 Быстрый старт

### Требования
*   **Браузер**: Google Chrome, Microsoft Edge или Opera (версия 90+).
*   **ОС**: Linux, Windows 10/11, macOS.
*   **Железо**: LEGO WeDo 2.0 Smart Hub.

### Установка
1.  Распакуйте архив в любую папку.
2.  **Не перемещайте** папки внутри архива относительно друг друга.

### Запуск

#### Вариант 1: Локальный (для одного компьютера)
Подходит для домашнего использования. Не требует установки серверов.
*   **Linux/Mac**: Откройте терминал в папке и запустите `./scripts/start-local.sh`
*   **Windows**: Запустите `scripts/start-local.bat`
*   Откройте в браузере: `http://localhost:8000`

#### Вариант 2: Серверный (для класса/лаборатории)
Подходит для клиентских подключений с компьютеров/планшетов по Wi-Fi. Требует установленного Nginx.
*   **Linux**: Запустите `sudo ./scripts/start-server.sh`
*   На клиенте откройте в браузере: `https://<IP-адрес-сервера>:8443`
*   *Примечание*: При первом входе браузер предупредит о небезопасном соединении (самоподписанный сертификат). Нажмите "Дополнительно" -> "Перейти на сайт".

#### Вариант 3: Облачный / Статический (для веб-хостинга)
Подходит для размещения на GitHub Pages, Netlify или любом хостинге с HTTPS.
*   Этот пакет (`wedo-studio-v2.5-cloud.zip`) содержит только файлы.
*   Загрузите содержимое папки `web` на ваш хостинг.
*   Откройте в браузере: `https://ваш-домен.com`
*   *Важно*: Web Bluetooth работает **только** по протоколу HTTPS.

## 🛠 Управление
1.  Введите название проекта в поле сверху.
2.  Нажмите **"🔌 Подключить хаб"** и выберите устройство в списке.
3.  Перетащите блоки из левой панели в рабочую область.
4.  Нажмите **"🏁 Запуск"** для выполнения программы (блоки будут подсвечиваться).
5.  Используйте **"💾 Сохранить"** для сохранения проекта в файл `.yaml`.
